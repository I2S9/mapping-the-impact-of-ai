# Mapping the Impact of AI through Data

Interactive data visualization website — Data Visualization course, Università di Genova (2026/27).

**Live site:** https://i2s9.github.io/mapping-the-impact-of-ai/

## Structure
- `index.html` — main page
- `css/style.css` — all styles (Roboto Slab for headings, Fira Sans for text)
- `data/` — cleaned datasets used by the visualizations

## Data sources
- Stanford HAI — AI Index Report 2026
- Our World in Data — Artificial Intelligence
- Eurostat — Use of AI in enterprises (isoc_eb_ai)
- Anthropic Economic Index (Hugging Face)
- OECD.AI Policy Observatory
